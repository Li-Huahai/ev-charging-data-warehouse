# 1. 项目概述

## 1.1 项目背景

随着电动汽车保有量快速增长，充电需求的时空分布呈现出显著的异质性与波动性。
充电需求的准确刻画对城市规划、设施运营与电网调度具有重要意义。

本项目围绕深圳市电动汽车充电行为，构建一套从数据采集、分布式存储与计算、
多维度分析到 Web 交互式可视化的完整技术栈，挖掘充电需求的时空规律及多因素耦合影响。

## 1.2 核心目标

1. **数据处理**：利用 Hadoop HDFS 存储海量原始数据，通过 Hive 构建企业级数据仓库，
   实现高效的数据管理与批处理分析。
2. **深度分析**：从时间、空间、价格、气温、兴趣点（POI）、充电站规模等多个维度，
   系统性地量化分析影响充电需求的关键因素及其交互作用。
3. **决策支持**：通过前后端分离的 Web 可视化平台，将复杂的分析结果以图表、地图等
   直观形式呈现，为城市规划、设施运营、电网调度等提供数据洞察。

## 1.3 关键利益相关者

- **最终用户**：城市规划部门、充电设施运营商、电网公司、电动汽车车主
- **开发团队**：李华海（学生），刘秋华（指导教师）
- **所属机构**：江西软件职业技术大学 软件工程学院

## 1.4 核心数据集

使用 Urbanev 开放基准数据集（Dryad 平台），8 大类 14 个文件：

| 类别 | 文件名称 | 描述 |
| :--- | :--- | :--- |
| 充电需求 | `volume.csv` | 各站点分时充电量 |
| 充电站状态 | `occupancy.csv` | 各站点分时占用率 |
| 价格数据 | `e_price.csv`, `s_price.csv` | 峰谷电价、服务费 |
| 气象数据 | `weather_airport.csv`, `weather_central.csv` | 机场和中心站气象数据 |
| 基础设施 | `infrastructure.csv` | 充电站地理位置、充电桩数量等 |
| 兴趣点(POI) | `poi.csv` | 周边兴趣点（餐饮、商业、生活服务等） |
| 空间关系 | `adjacency.csv`, `distance.csv` | 站点间邻接矩阵与距离矩阵 |
| 充电时长 | `duration.csv` | 充电会话持续时间 |
